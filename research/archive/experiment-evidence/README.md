# Historical experiment evidence

This directory preserves earlier GPU runs, benchmark results and diagnostic logs from V1–V3 development.

These are research records, not active runtime configuration or universal performance guarantees.

The original path of each moved file is recorded in MOVED_FILES.tsv.

Some referenced evidence remains at its original path to preserve older scripts.

Archived resources may contain historical AWS resource identifiers. Archiving does not make the contents private or remove Git history.
