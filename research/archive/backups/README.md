# Historical Development Backups

This directory preserves snapshots from earlier development
and debugging work on the distributed inference framework.

These files are not part of the supported public API.

The original filenames and directory layout have been
preserved beneath this archive.

Do not run archived scripts as deployment or maintenance
entry points. Some may depend on obsolete paths, APIs,
or infrastructure assumptions.

See the V3.4 freeze branch and Git history for the
original development context.
